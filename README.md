# CodeAlpha Internship Projects

This repository contains the projects completed as part of my CodeAlpha Internship.

## Projects

### 1. Web Scraping Project

A Python web scraping project that extracts book information from the Books to Scrape website.

**Technologies Used:**

* Python
* Requests
* BeautifulSoup
* CSV

**Files:**

* `web_scraping.py` – Web scraping program
* `books.csv` – Scraped book data

---

### 2. Exploratory Data Analysis (EDA)

An Exploratory Data Analysis project using the Online Retail dataset to analyze data structure, data quality, trends, patterns, and anomalies.

**Technologies Used:**

* Python
* Pandas
* Matplotlib
* Seaborn

**Files:**

* `eda_analysis.py` – EDA and data analysis
* `main.py` – Main Python file

---

### 3. Data Visualization

A data visualization project based on the Online Retail dataset.

The project creates visualizations to understand sales trends and patterns.

**Technologies Used:**

* Python
* Pandas
* Matplotlib
* Seaborn

**File:**

* `task3_visualization.py` – Data visualization program

**Visualizations Include:**

* Monthly Sales Trend
* Sales Analysis
* Business data patterns
